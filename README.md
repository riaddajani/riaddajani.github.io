# riaddajani.github.io

A minimalist, researcher-style personal site for **Riad Dajani**.  
Built with plain HTML/CSS (no framework) and designed to be easy to maintain.

## 🚀 Quick start
1. Create a public repo named **riaddajani.github.io** on GitHub.
2. Upload the files in this folder to the repo root.
3. In **Settings → Pages**, set Source = **Deploy from a branch** and Branch = **main**.
4. Your site will be live at https://riaddajani.github.io/

## 🧱 Structure
```
/
├─ index.html
├─ projects/
│  ├─ index.html
│  ├─ brainlang.html
│  ├─ braintoken.html
│  ├─ superpower-social.html
│  └─ text2tone.html
└─ assets/
   ├─ styles.css
   ├─ profile.svg (placeholder)
   └─ favicon.svg
```

## 📝 Personalizing
- Replace **assets/profile.svg** with a real headshot at `assets/profile.jpg` (and update `index.html`).
- Add a **cv.pdf** at the repo root and uncomment the button in `index.html`.
- Edit project pages under `/projects` as work evolves.
- Colors adapt to the user's OS light/dark mode. Tweak in `assets/styles.css`.

## 🧠 Philosophy
The content and layout emphasize a clear mission — *enhancing cognitive bandwidth* — and connect each project back to it.
