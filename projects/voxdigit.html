VoxDigit

Fast, tiny, and live spoken-digit recognition with early-exit, few-shot enrollment, and interpretability.

View on GitHub ↗

What it is

A compact CNN-based system for real-time spoken digit recognition (0-9) that achieves ~99.7% accuracy on the Free Spoken Digit Dataset while maintaining extremely low latency. The system supports live microphone input, early-exit predictions, and few-shot speaker enrollment—all running efficiently on CPU.

Why it matters

This project demonstrates how to build practical, interpretable speech recognition systems that are fast enough and smart enough for real-world use:

  • Early-exit inference: Makes confident predictions before utterances complete, reducing perceived latency
  • Few-shot enrollment: Adapts to new speakers, microphones, languages, or domains in seconds via prototype learning (tested with Arabic)
  • Interpretability: Shows confusion matrices during training and gradient saliency ("why") during live inference
  • Tiny footprint: 3-layer CNN + 3-layer MLP runs feature extraction and inference in milliseconds on CPU

Technical approach

Architecture

  • Features: Fixed-size 64×64 MFCC "images" with dataset-level normalization
  • Model: 3 Conv layers (BN+ReLU) → MaxPool → 3 Dense layers (BN+ReLU) with dropout
  • Training: Adadelta optimizer, cross-entropy loss, batch size 64, ~50 epochs
  • Augmentation: Light time-shift and noise injection for robustness

Key innovations

  • Early-exit logic: During streaming inference, computes features over growing buffers and exits when confidence exceeds threshold for N consecutive checks
  • Prototype head: Extracts CNN embeddings and stores per-digit prototypes in cosine space; blends CNN probabilities with prototype similarities for hybrid predictions
  • Live interpretability: Highlights MFCC bands with strongest gradient saliency for predicted class
  • Voice Activity Detection (VAD): Intelligent segmentation for robust microphone input

Results

  • Test accuracy: 99.67%
  • Macro F1: 99.67%
  • Early-exit: Triggers at p > 0.88 confidence
  • Latency: Feature extraction + forward pass in milliseconds on CPU

Use cases

This architecture and training pipeline are useful for:

  • Voice-controlled interfaces requiring digit input (PIN codes, phone numbers)
  • Low-latency spoken digit recognition in resource-constrained environments
  • Few-shot adaptation to new speakers without retraining
  • Educational demonstrations of interpretable audio classification

Features

  • Training mode: Train CNN on FSDD with confusion matrix tracking
  • Evaluation mode: Test accuracy and F1 on held-out split
  • Live mode: Real-time microphone input with early-exit and VAD
  • Enrollment mode: Record your own digits for few-shot prototype adaptation
  • Hybrid inference: Blend CNN predictions with enrolled prototypes

Technical notes

  • Built on well-tested FSDD baselines from sound-mnist
  • Uses Hugging Face datasets for FSDD loading
  • Requires PortAudio for microphone input (via sounddevice)
  • All normalization statistics cached for consistency across runs
  • Single Python file implementation for easy experimentation

Status

Complete and functional. Demonstrates production-ready patterns for low-latency, interpretable speech recognition with adaptive enrollment.
