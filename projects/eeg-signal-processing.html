EEG Signal Processing CogSci BCI

Classifying eyes-open vs eyes-closed from occipital EEG, then moving a mouse cursor with the output. My first attempt at brain-computer interfacing.

View Notebook ↗ Read Report (PDF)

The backstory

In 2022, I was a Global Business & Digital Arts student at UWaterloo who had pivoted hard into cognitive science. I'd spent years thinking about enhancing cognitive bandwidth—making human-computer interaction faster, richer, more intuitive—but I had zero experience with scientific coding, signal processing, or writing academic papers.

PSYCH 420 (Introduction to Computational Neuroscience) with Dr. Britt Anderson was my crash course. By the end, I wanted to build something that actually touched the brain. This project, co-authored with Wasam Syed, was my first conceptual demo: read brain signals, classify a mental state, do something with it.

What we built

A complete (if scrappy) BCI pipeline:

  1. Data: SPIS resting-state EEG from 20 subjects—recordings from occipital electrodes under two conditions: eyes open and eyes closed
  2. Signal processing: Discrete Fourier Transform → Power Spectral Density extraction at 256 Hz. The alpha band (8-13 Hz) shows clear differences between conditions—eyes closed = stronger alpha
  3. Classification: A multilayer perceptron we wrote from scratch. Sigmoid activations, MSE loss, gradient descent with backpropagation. No PyTorch, no TensorFlow—just numpy and determination
  4. Output: Mouse cursor control via PySimpleGUI. The classifier's prediction moved the cursor. Brain → screen.

Pipeline walkthrough

1. Data extraction & standardization

We pulled raw EEG from the SPIS resting-state dataset (channel 25, 1000 samples at 4 ms resolution). Each condition—eyes closed and eyes open—was mean-centered to remove DC offset, giving us a standardized voltage trace to work with.

2. Fourier analysis & denoising

We applied scipy.fftpack.fft to decompose the time-domain signal into frequency components. The raw FFT reveals a dominant low-frequency peak with high-frequency noise spread across the spectrum. We isolated the peak frequency and zeroed out everything above it, then inverse-transformed back to get a filtered signal.

3. Feature extraction — Power Spectral Density

Using Welch's method (scipy.signal.welch) on the occipital electrode (O1) at 256 Hz sampling rate, we computed the PSD for both conditions. This is where the signal becomes meaningful: the eyes-closed condition shows elevated power in the alpha band (~8–13 Hz), consistent with the well-known alpha suppression effect when eyes open.

4. Classification — from-scratch neural network

We built a 2→3→1 multilayer perceptron entirely in NumPy. The input features were the condition mean (as a proxy for signal statistics) and a sample index, normalized to [0,1]. Sigmoid activations, MSE cost function, and manual backpropagation with a learning rate of 3. The learning curve converges quickly—cost drops from 0.5 to near-zero within the first few hundred iterations.

5. Application — simulated BCI output

The trained network maps its binary prediction to a cursor action: eyes open → move up, eyes closed → move down. Here are the results on the training samples:

Sample 1: Input [-0.196, 0.25] → Output 0.9995 → Eyes Open → Mouse UP Sample 2: Input [-0.196, 0.50] → Output 0.9335 → Eyes Open → Mouse UP Sample 3: Input [ 1.00, 0.75] → Output 0.0363 → Eyes Closed → Mouse DOWN Sample 4: Input [-1.00, 1.00] → Output 0.0519 → Eyes Closed → Mouse DOWN

The raw outputs are well-separated—open predictions cluster near 1.0, closed near 0.0—showing the network learned a clean decision boundary despite the tiny dataset.

The paper (and its problems)

This was my first scientific paper. It shows.

  • We gave up on denoising: The report literally says we "attempted to denoise the signal using scipy.fft but were struggling with deriving meaningful information out of the denoised signal so opted to use the non-denoised signal." Translation: we tried, got confused, and just... moved on.
  • The conclusion is two sentences: "Our report shows how powerful a simple implementation of EEG Signal Processing can be. At a higher scale this methodology has many possibilities." That's it. That's the whole conclusion.
  • Half the paper explains what neural networks are: We spent pages explaining sigmoid functions and backpropagation to... ourselves? The professor? I'm still not sure who the audience was.
  • No proper evaluation metrics: We didn't report accuracy, precision, recall, or even a confusion matrix. The model "worked" but we had no rigorous way to say how well.

Why it mattered anyway

Despite the rough edges, this project proved something to me: the loop from brain to action is possible with accessible tools. You can:

  • Read electrical signals from the scalp
  • Extract features that correspond to cognitive states
  • Train a simple model to classify them
  • Close the loop with real-time output

The demo was trivial (moving a cursor based on whether someone's eyes were open), but the pattern was the whole point. Enhancing cognitive bandwidth starts with proving you can decode anything at all.

What I learned

  • The International 10-10 electrode placement system (and why occipital electrodes matter for visual states)
  • How FFT decomposes signals into frequency components
  • Why alpha waves dominate during eyes-closed relaxation
  • How to implement backpropagation by hand (painful but instructive)
  • That scientific writing is a skill I did not yet have

Related work

The foundational models I built in that same period—perceptrons, delta rule, Hodgkin-Huxley simulations—gave me the building blocks to understand what we were doing here. This project was where those pieces came together into something that actually touched the real world.
