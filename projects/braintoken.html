BrainToken in progress

Neural-to-Text Decoding via JEPA and Perplexity-Guided Learning

Abstract

This project implements a novel neural decoding system that translates ECoG brain signals into natural language using a multi-stage architecture combining Joint Embedding Predictive Architecture (JEPA) with perplexity-guided soft prompting. The system leverages pretrained EEG-VJEPA encoders (X-encoder for context, Y-encoder for targets) with a learned predictor module to extract meaningful representations from high-gamma ECoG signals. These representations are projected into soft prompts that condition a frozen large language model (Gemma-2-2B) to generate corresponding text sequences.

Key Innovation

The key innovation lies in the dual-objective training paradigm:

  1. Perplexity minimization (PP(W)) that optimizes the entire pipeline to produce text-predictive representations, with gradients flowing back through the projection layer, predictor, and both encoders
  2. JEPA reconstruction loss that grounds the predictor in meaningful latent structure

This approach addresses the critical challenge of mode collapse where standard perplexity-only training produces generic prompts that ignore neural input.

Dataset & Architecture

Trained on the Podcast ECoG dataset (5,130 word epochs from a single subject with 99 channels at 256Hz), the system processes 4-second windows of neural activity through spatiotemporal encoding, achieving trainable parameter counts of ~431M (with 1.6B frozen LLM parameters).

The architecture employs automatic mixed precision training, gradient accumulation, and learning rate warmup to ensure stable optimization despite the complex multi-component gradient flow.

Significance

The system represents a significant advance in brain-computer interfaces by demonstrating how modern foundation models (both vision transformers for neural signals and language models for generation) can be effectively combined through learnable soft prompting, providing a path toward high-fidelity neural decoding without task-specific supervised datasets.

Status

Active development. Training pipeline operational, evaluating on held-out epochs.
