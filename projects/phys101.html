Physics-Informed Video Learning

Multi-task pretraining and efficient fine-tuning to predict physical properties from video.

Overview

Using the Phys101 dataset (objects in motion across ramp, spring, fall, liquid scenarios), this project explores learning physical properties directly from video:

  • Mass and volume from object metadata
  • Velocity via optical flow pseudo-labels (normalized px/s)
  • Energy proxy derived from 0.5·m·v²

Approach

  1. Self-supervised warmup: NT-Xent contrastive learning on video clips
  2. Multi-task supervised: Joint regression heads for mass, volume, velocity, energy + material classification
  3. Efficient fine-tuning: LoRA adapters on MobileNetV3 + tiny temporal Transformer

Notebooks

Multi-Task Pretraining

R3D-18 backbone with self-supervised warmup and multi-task regression heads.

LoRA Fine-Tuning

MobileNetV3-Small + temporal Transformer with LoRA adapters. AMP mixed precision, velocity caching.
