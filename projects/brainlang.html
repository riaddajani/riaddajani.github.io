BrainLang

Decoding heard language from fMRI into text-space representations.

View Notebook ↗ Read Report (PDF)

What it is

BrainLang explores continuous language decoding from non-invasive fMRI while a subject listens to narrative speech. The v0.1 model uses UMAP to reduce dimensionality of voxel time series, a BiLSTM encoder (512 units) with attention, and a seq2seq-style language decoder. Total: 7.5M parameters.

Why it matters

Enhancing cognitive bandwidth means shortening the path from brain to useful representation. Even imperfect readouts can function as a low-rate channel that bootstraps assistance, communication, or model alignment.

Technical notes

  • Dataset: LeBel et al. (2023) natural language fMRI dataset—8 participants listening to 27 stories from The Moth
  • Preprocessing: UMAP (n_neighbors=50, min_dist=0.1) → StandardScaler → sequence batching
  • Model: BiLSTM encoder + attention + LSTM decoder with 4,407-word vocabulary
  • Training: Teacher forcing, batch size 32, early stopping, learning rate reduction
  • Result: 31.67% token accuracy—captures some phrases but with repetitive outputs

Lessons Learned (v0.1 Failures)

The v0.1 implementation had critical methodological flaws that artificially inflated performance:

1. Teacher Forcing at Inference

During prediction, the model was given ground-truth decoder inputs at every step (model.predict([encoder_input, decoder_input])). This means it wasn't actually generating text—just predicting the next word given the correct history. Real generation must be autoregressive: predict word 1, feed that prediction back as input for word 2, and so on.

2. Validation Leakage

Testing was done on the last 2 samples, which overlapped with the validation set used for early stopping. The model's weights were selected based on performance on these samples, so it was biased to perform well on them. Proper evaluation requires a held-out test set the model never sees during training or checkpoint selection.

3. Limited Data

With only 27 story samples across 8 subjects, the model had insufficient data to learn generalizable brain-to-text mappings. The high train/val accuracy divergence (Figure 5 in the report) shows clear overfitting.

Status

v0.1 is archived as a learning experience. Current work (v2) focuses on:

  • Proper autoregressive inference
  • Strict train/val/test splits
  • Contrastive evaluation baselines
  • Comparison with discrete phrase classification (following Tang et al. 2023)
