Context

Some of these come from PSYCH 420 (Computational Neuroscience) and related coursework at UWaterloo—where I first made the jump from business into computational cognitive science and ML. Others are personal projects I built on my own time to learn concepts I was curious about. In both cases, each notebook was an exercise in understanding one concept deeply enough to implement it—no libraries doing the heavy lifting, just NumPy and matplotlib.

They're rough, but they gave me the intuitions I still rely on: how neurons spike, how networks remember, how learning rules converge, how systems stabilize. The EEG project was where these pieces first came together into something real.

The models

Perceptron

The simplest possible neural classifier. A single unit with a threshold activation and a weight update rule. Learns to separate linearly separable classes—and fails (instructively) on everything else. This was my first "aha" for why depth matters.

Delta Rule (LMS)

Error-driven learning: compute the difference between target and output, nudge weights proportionally. Visualizes how a decision boundary converges on 2D data. The gradient descent intuition I built here carried directly into understanding backpropagation.

Hodgkin–Huxley

The biophysical model of action potentials—sodium and potassium channel dynamics, membrane capacitance, the works. Simulating this taught me what a neural "signal" actually looks like at the lowest level: not a 0 or 1, but a voltage trajectory shaped by ion kinetics.

Hopfield Network

Associative memory as energy minimization. Store patterns as attractors, then watch the network recover them from noisy or partial inputs. The connection to content-addressable memory and modern attention mechanisms became clear only later.

Damped Oscillator

A spring-mass system with friction, solved via Euler's method. Straightforward physics, but it built intuition for stability and resonance that shows up everywhere—from neural oscillations to control systems to why some training runs diverge.

H&H → PSD → MLP

A pipeline experiment: generate Hodgkin-Huxley spike trains, decompose them with FFT, then train an MLP to reconstruct the signal from its frequency features. This was me trying to connect the biophysical models to the machine learning ones—a signal processing chain from neuron to network.

Marr–Hildreth Edge Detection

Laplacian of Gaussian for finding edges via zero-crossings. Classical computer vision from first principles. Implementing this made Marr's levels-of-analysis framework concrete: what the computation is, why it works, and how it's realized.

Conv-RNN + RSA

A hybrid convolutional-recurrent network on CIFAR-10, with hyperparameter search and Representational Similarity Analysis. The RSA part was the interesting bit—comparing the network's internal representations to see which layers encode what, borrowing a method straight from cognitive neuroscience.
